# Log-Based Metric Implementation

## Objective

To create a custom detection metric based on security-relevant log activity.

## Metric Details

Metric Name:

vm_activity_metric

Metric Type:

Counter Metric

## Filter Used

resource.type="gce_instance"

Alternative Filter:

protoPayload.serviceName="compute.googleapis.com"

## Implementation Steps

1. Opened Cloud Logging.
2. Navigated to Log-Based Metrics.
3. Created a custom counter metric.
4. Applied a Compute Engine activity filter.
5. Saved the metric configuration.
6. Generated activity by interacting with VM resources.

## Validation

The metric successfully collected audit activity generated by Compute Engine operations.

## Security Benefits

- Converts logs into measurable events.
- Enables automated monitoring.
- Supports alert generation.
- Improves visibility of infrastructure activity.

## Outcome

Successfully implemented a custom security monitoring metric for VM activity detection.
