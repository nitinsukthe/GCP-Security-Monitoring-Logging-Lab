# Project Overview

## Project Title

GCP Security Monitoring and Logging Lab

## Objective

The objective of this project was to implement and evaluate cloud-native security monitoring capabilities in Google Cloud Platform (GCP).

The project focused on collecting audit logs, monitoring resource activity, creating custom detection metrics, configuring monitoring alerts, and reviewing Identity and Access Management (IAM) permissions.

## Technologies Used

- Google Cloud Platform (GCP)
- Cloud Logging
- Cloud Audit Logs
- Compute Engine
- Log-Based Metrics
- Cloud Monitoring
- IAM & Admin

## Security Domains Covered

- Cloud Security Monitoring
- Audit Logging
- Security Detection Engineering
- IAM Security Review
- Security Posture Assessment
- Incident Detection and Alerting

## Key Activities

- Created a dedicated GCP security monitoring project
- Enabled monitoring and logging APIs
- Investigated Security Command Center availability
- Collected and analyzed Cloud Audit Logs
- Deployed a Compute Engine virtual machine
- Created custom Log-Based Metrics
- Configured Cloud Monitoring alert policies
- Reviewed IAM roles and permissions
- Applied cloud security best practices

## Project Outcome

Successfully implemented a cloud security monitoring workflow capable of collecting audit logs, generating security metrics, detecting activity through alert policies, and identifying IAM security risks.
